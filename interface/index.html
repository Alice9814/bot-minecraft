Compatibilidade: somente Minecraft Java Edition

O ProtoBot se conecta a servidores Java. Para jogar pelo Bedrock, o servidor Java precisa aceitar conexões Bedrock por meio do GeyserMC.

Floodgate: não é obrigatório em todos os casos. Em servidores Java com online-mode=true, use Floodgate se quiser permitir que jogadores Bedrock entrem sem uma conta Java. Sem Floodgate, eles precisarão autenticar com uma conta Java. Em servidores com online-mode=false, o Geyser pode usar autenticação offline sem Floodgate, mas esse modo é inseguro e permite falsificação de nomes; use Floodgate quando quiser autenticação Bedrock própria.

O ProtoBot continua sendo um cliente Java; GeyserMC adapta as conexões dos jogadores Bedrock ao servidor Java, não transforma o bot em cliente Bedrock.
